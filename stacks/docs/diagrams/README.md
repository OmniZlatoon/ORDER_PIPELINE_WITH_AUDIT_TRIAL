# Viewing the architecture diagram in Eraser

The `.eraser` file contains the diagram source in Eraser's diagram-as-code format.

1. Open [eraser.io](https://eraser.io) and sign in.
2. Create a new diagram (or open an existing diagram) and choose **Diagram as code** / **Code** in the editor.
3. Open `order-pipeline-architecture.eraser` in a text editor, copy its contents, and paste them into Eraser's code editor.
4. Allow Eraser to render the code. Make edits in the code editor to update the diagram; save the diagram in your Eraser workspace if you want to keep it there.

The rendered PNG preview in this folder is `order_pipeline_Architectural_diagram.png`.
